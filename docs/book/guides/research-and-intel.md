# Guide — Research and intel

How Vaerion turns local documents into cited, replayable context for agents
— the **One Context Path** (ADR-0005 tiered intelligence, ADR-0008 local
stores).

## Capability declarations

Research is declared, never ambient:

```yaml
research:
  capabilities:
    - name: project-docs
      sources:
        - { kind: local, path: "./docs" }
      fencing: untrusted
      maxItems: 100
```

A declaration is turned into a signed capability with a fingerprint; every
subsequent step references it. Unknown source kinds and undeclared paths are
refused — the ceiling is the permission graph, and research sources are part
of it.

## The One Context Path

Every context fetch — CLI `run research`, agent `context` steps, workflow
`context` nodes — crosses the same pipeline:

```
declared capability → broker decision (research.fetch, per source) →
fingerprint → fence → blob CAS → evidence record → local index → query →
BM25 scoring → citations → context pack → journaled verify → replay equality
```

The pack carries provenance (source, fingerprint, evidence ids). There is no
side door that hands text to a model: if context was used, citations are
enforceable — an **answer step that used research context but omits citations
is refused (E1806)**.

## The local index

The `LocalIndex` is a deterministic BM25 index: same docs, same query, same
scores — with a total order tiebreak so ranked lists are byte-stable.
`replace-on-reindex` is the update law (no incremental drift). Limits are
honored exactly; limit × determinism is test-asserted.

Tiering (ADR-0005): tier-1a is this local lexical path — always available,
offline, fast. Embedding-backed tiers are progressive enhancement behind the
same contracts; the tier-1 path never depends on them.

## Fencing

Source content is **untrusted input**. It is fenced before it can influence
a run: provenance is attached at read time, citations reference evidence
records (not raw strings), and the journal stores hashes so a pack can be
reconstructed and replayed byte-identically.

## Ops notes

- `vae run demo` is the zero-config tour (repository docs as sources).
- `vae doctor` triangulates evidence ↔ blob ↔ fingerprint; a mismatch is a
  loud E-code, not a silent skip.
- Index throughput is a measured budget (OBJ-Q5 ≥ 12k files/min typical mixed
  repo); the current measurement lives in `PERFORMANCE.md` at the repository
  root, generated by `packages/vaerion/scripts/perf-check.ts`.
